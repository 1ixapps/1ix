# ممیزی آماده‌سازی انتشار — ۲۰۲۶/۱۰/۲۲

یادداشت ساختار ۲۰۲۶/۱۰/۲۷: محتوای frontend و .git به ریشهٔ ریپو منتقل شدند؛ فایل‌های قدیمی بیرون برنامه از ریپو خارج و در بک‌آپ محلی قابل‌بازیابی نگه‌داری شدند. نتایج تست و بررسی امنیتی زیر مربوط به تاریخ ممیزی‌اند؛ هشدار High مربوط به Zod در بررسی ۲۰۲۶/۱۰/۲۶ گزارش شد و انتقال پوشه‌ها آن را رفع نمی‌کند.

## دامنهٔ بررسی

کد Next.js، مسیرهای صفحات و API، نشست و تأیید ایمیل Supabase، schema و ابزارهای انتقال، SEO، رندر HTML عمومی، تعرفه‌ها و تست‌های موجود بررسی شد.
این ممیزی تضمین نبود هر باگ ممکن یا تست نفوذ کامل نیست. هیچ تغییر یا migration روی دیتابیس ابری، ارسال ایمیل واقعی، تغییر DNS یا دیپلوی واقعی انجام نشد.

## رفع‌شده در این مرحله

- وابستگی کامل محتوای عمومی به JavaScript: همان رابط موجود اکنون از سرور HTML می‌گیرد و در مرورگر hydrate می‌شود.
- عنوان مشترک و canonical/OG ناقص مسیرها: متادیتای مستقل و منبع مشترک امن برای خانه، تعرفه و کسب‌وکار اضافه شد.
- نبود sitemap/robots: مسیرهای واقعی با فیلتر انتشار و تعلیق اضافه شد.
- soft-404 آدرس‌های ناشناخته: پاسخ HTTP ۴۰۴ و صفحهٔ فارسی اضافه شد.
- استفاده از favicon.svg به‌عنوان تصویر اشتراک: PNG اختصاصی اضافه شد.
- اطلاعات ساختاریافتهٔ باقی‌مانده بعد از جابه‌جایی صفحه: پاک‌سازی و robots در ناوبری اصلاح شد.
- درخواست دوباره برای تعرفه‌ها در بارگذاری اولیه: پلن واقعی سرور به رابط داده می‌شود؛ در ناوبری از مسیر بدون seed، API موجود باقی است.
- وعدهٔ فعال‌سازی آنی/محاسبهٔ خودکار ارتقا در متن تعرفه‌ها: با تمدید هماهنگ‌شده از پشتیبانی جایگزین شد.
- نمونهٔ env حاوی آدرس پروژهٔ مشخص: با placeholder بی‌خطر جایگزین شد؛ env واقعی دست‌نخورده است.
- راهنمای جداگانهٔ دیپلوی، تغییر مقصد دیتابیس، نصب SQL و بررسی فقط‌خواندنی اضافه شد.

## مواردی که پیش از انتشار عمومی باید تعیین تکلیف شوند

۱. امنیت گیت: در انتقال ساختار مورخ ۲۰۲۶/۱۰/۲۷، .env از index خارج و فایل محلی حفظ شد. حذفِ ثبت آن را در commit بعدی نگه دارید؛ اگر secret قبلاً push شده، تعویضش کنید. تاریخچهٔ قبلی گیت بازنویسی نشده است.

۲. پلن‌ها: نقش و تاریخ انقضای حساب محاسبه می‌شود، ولی محدودیت تجاری امکانات در API به‌طور کامل enforce نمی‌شود. برای مثال سهمیهٔ «۵ لینک» در ایجاد لینک محدود نشده است. هیچ محدودیت یا پرداخت جدیدی بدون تعریف محصول تحمیل نشده.
بعضی ادعاهای فعلی در plans.mjs/جدول مقایسه مانند چندکارمند، اتصال دامنه، API عمومی و حذف برند پیاده‌سازی عملی کامل ندارند. پیش از فروش، یا متن این امکانات از تعرفه حذف شود، یا جریان واقعی و آزمون دسترسی هر پلن پیاده‌سازی شود. قیمت‌ها و حقوق دسترسی کاربران در این مرحله تغییر نکرده‌اند.

۳. تمدید اشتراک: هماهنگی از تلگرام انجام می‌شود، نه درگاه خودکار. UI مدیر فعلاً همهٔ تاریخ‌های شروع/پایان اشتراک را مدیریت نمی‌کند؛ پیش از فروش اشتراک زمان‌دار، گردش دقیق تمدید و انقضا باید تکمیل و تست شود.

۴. تعویض Supabase موجود: ابزار عمومی خودکار برای کپی PostgreSQL-to-PostgreSQL، Auth و Storage و بازنویسی URL تصاویر وجود ندارد. راهنما مراحل و خطرها را جدا توضیح می‌دهد؛ فقط تغییر URI انتقال نیست.

۵. تنظیمات ابری: بررسی فقطِ حضور متغیرها در env فعلی نشان داد DATABASE_URL، SUPABASE_URL و کلید عمومی Auth وجود دارند، اما SITE_URL، NEXT_PUBLIC_SITE_URL و کلید سمت سرور Storage تنظیم نیستند. این موارد را برای انتشار طبق DEPLOYMENT.md تکمیل کنید؛ هیچ مقدار محرمانه‌ای در گزارش ثبت نشده و env واقعی تغییر نکرده است. SMTP، Confirm email، callbackها، DNS، کلیدهای واقعی و وضعیت bucket باید در حساب شما بررسی شوند. تست‌های محلی آن‌ها را تأیید نمی‌کنند. هیچ ایمیل یا رزرو واقعی در تولید ساخته نشده است.

۶. مرورگر: اتصال ابزار مرورگر به‌دلیل خطای محیط Windows برقرار نشد؛ بررسی تصویری/تعامل واقعی مرورگر و hydration در سایت زنده هنوز لازم است. تست DOM، پاسخ HTTP نسخهٔ production و build جایگزین شده‌اند.

۷. زیرساخت: rate limit و جلوگیری از سوءاستفاده در رزرو عمومی/پشتیبانی، سیاست نگهداری IP و اطلاعات مشتری، پشتیبان‌گیری و مانیتورینگ تولید نیاز به سیاست عملیاتی دارند. تست نفوذ مستقل انجام نشده است.

۸. مقیاس سئو: sitemap فعلاً سقف ۲۰هزار صفحه دارد؛ برای رشد بیشتر، sitemap index لازم است. Search Console، رتبه و Core Web Vitals زنده هنوز سنجیده نشده‌اند.

## روش اعتبارسنجی

از ریشهٔ پروژه، کنار package.json:
- npm test -- --watchAll=false --runInBand
- npm run test:server
- npm run build
- npm run test:smoke
- npm audit --omit=dev --audit-level=high

تست جدید سرور، تطابق SETUP.sql با migrationها، اجرای دوباره، RLS، محدودبودن خواندن عمومی و تغییرنکردن شمارنده‌ها را روی PostgreSQL تعبیه‌شده بررسی می‌کند.
تست smoke محتوای اولیهٔ HTML، metadata، تصویر PNG، robots، sitemap، ۴۰۴، assets و مسیرهای API را بدون اتصال به cloud بررسی می‌کند.
نتیجهٔ اجرای این مرحله:
- ۱۸۶ تست رابط در ۲۸ مجموعه: موفق.
- ۷۴ تست سرور: موفق.
- build نسخهٔ production: موفق.
- ۴۳ بررسی HTTP/asset/metadata/API: موفق.
- npm audit --omit=dev --audit-level=high --fetch-retries=0 --fetch-timeout=15000: صفر آسیب‌پذیری گزارش‌شده در وابستگی‌های runtime.
- diff --check برای فایل‌های تغییرکرده: موفق.
هشدار قدیمی‌بودن دادهٔ Browserslist و deprecation مربوط به ابزارهای تست باقی است؛ مانع build نبودند. این مرحله ادعای lint سراسری ندارد؛ اسکریپت lint/typecheck مستقل در package.json تعریف نشده است.
